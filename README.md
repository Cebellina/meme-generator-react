# Meme Generator

En meme generator byggd med React, TypeScript, Vite och html2canvas.

## Funktioner

- Välj meme-bild
- Byt bild när som helst
- Top text och bottom text
- Texten visas direkt på bilden
- Textfälten rensas när man byter bild
- Ändra textstorlek med sliders
- Ladda ner färdig meme som PNG
- All state ligger i App.tsx
- Övriga komponenter är dumma komponenter

## Starta projektet

```bash
npm install
npm run dev
```

## Bygga projektet

```bash
npm run build
```
